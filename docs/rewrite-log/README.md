# Rewrite Log

Create one entry for each meaningful milestone, not every coding session. Use `YYYY-MM-DD-short-topic.md` as the filename.

Keep entries factual and concise. Record the starting point, decisions, completed work, problems, lessons, evidence, and next step. Include related commit hashes when available.

Suggested structure:

```markdown
# Milestone title

Date: YYYY-MM-DD
Related commits: `commit`

## Goal

## Starting point

## Decisions

## Work completed

## Problems encountered

## What we learned

## Result

## Next step
```

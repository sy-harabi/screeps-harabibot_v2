Notes

Runs the browser port of harabibot v2 base planner snapshot 7187a457. Tower comparison reuses the exact v2 tower candidate collector and slot/spawn capacity limits. Central finds the minimum feasible radius around the theoretical minimax center region, expands the candidate radius by three tiles, then runs a width-64 beam search scored by min damage, weak-count, total damage, and center distance. Its certificate always evaluates at least the three lowest-damage ramparts. Distributed is evaluated only when central is not certified. Distributed picks one seed near each diameter endpoint, then chooses the remaining four with the current v2 weakest-rampart logic: target the weakest rampart, keep candidates within minimum range + 1, then prefer minimum average range to all ramparts. MILP uses the same feasible candidate model with 30 s primary / 3 s tie-break limits.
Map data: live shardSeason room API. Structure sprites: admon84/screeps-room-planner (MIT). Extension rendering uses the official Screeps renderer extension texture/border assets and falls back to the same circle geometry if those assets cannot load.
